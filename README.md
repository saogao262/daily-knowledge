# Daily Knowledge

A daily timeline game for general knowledge. Every day you get five events from history, science, geography, inventions, and the news. Put them in order on a timeline, find out why each one matters, and keep your streak going.

**Status:** being set up. No playable version yet. See [PLAN.md](PLAN.md).

## Tech

TypeScript + Vite, hosted on GitHub Pages. The puzzles are written ahead of time and stored in this repo.

## Running locally

Once the app is scaffolded:

```bash
npm install
npm run dev
```
