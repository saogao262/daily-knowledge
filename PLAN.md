## The app

A daily news and knowledge site that makes you remember, not just read. Each day it shows short **World** and **US** highlights pulled automatically from several news outlets. A story is shown only when 2 or more credible outlets with different political leanings report it, and every outlet that covered it is listed and linked. **Topic pages** follow 4–6 major ongoing stories (for example the Ukraine war and Israel–Palestine) with background, a timeline of key dates, and the latest highlights. A **weekly quiz** (a timeline round where you order the week's events, plus a few multiple-choice questions) tests what you saw. **Spaced repetition** brings back the questions you missed until they stick. Static TypeScript + Vite site on GitHub Pages. A scheduled GitHub Action updates the headlines every day, and the agent writes the quiz and topic updates weekly for Amy to skim.

**Why (Amy, 2026-10-27):** "I think I lack a lot of general knowledge, including history, current events, politics, geography etc. I want a fun easy daily sort of thing that will solve this."

Inspired by this quote: "I think AI is currently creating two categories of students. The first one being the ones that use it to learn everything. The second one being the ones that use it to never learn anything ever again. The second group is much bigger."

So the app should push toward the first group. Amy should actually learn and remember things, which means recalling answers, not just reading them. It should also stay fun and easy enough to do every day.

## Decisions

- 2026-11-01: **How review works.** The waits are 3 days, then 1 week, 2 weeks, and 1 month. Any wrong answer starts over at 3 days, and a right answer at the 1-month review retires the item. Review items count from the date the quiz was finished (Central time). The card shows all due items oldest first, with no daily cap for now because there are only up to 10 misses a week. Timeline cards are reviewed as "When did this happen?" using the 3 nearest dates from the same week, so the choices are close and you have to actually remember. The alternative was re-placing the card on a timeline, which is more work for a short daily review.
- 2026-10-31: **Quiz format: published Saturdays, covering Saturday to Friday, with 5 timeline cards plus 5 questions.** Amy chose Saturday and 5 questions (about 5 minutes). Each quiz is listed in chat for Amy's OK before it goes live. Only the first finish of a week counts toward the score and streak, and replays are just practice. The streak counts consecutive weeks finished, and this week's quiz doesn't break it until the week is over. Quiz events are checked against the original or a major outlet. Events whose exact day was unclear (like the Binance hack) became questions instead of timeline cards. In dark mode the "wrong" orange is darker so it doesn't look like the light blue "right".
- 2026-10-31: **Topics are tagged automatically by keywords.** A story gets a topic when any outlet's headline contains one of the topic's keywords as a whole word (so "AI" doesn't match "said"). The midterms topic only tags US stories, so foreign elections don't count. The alternative was the agent tagging stories weekly, which is more accurate but up to a week late. Known weakness: broad keywords (e.g. "campaign", "Republicans") can over-tag during election season. Crypto is grouped under AI and tech policy.
- 2026-10-31: **Topic backgrounds cite news reports for recent events and Wikipedia for settled history.** Some publishers (Britannica, BLS, OpenAI) block automated link checks, so links that could be verified were preferred. Key dates use only the precision the sources support (for example "September 2026" for the Fed's hike). The backgrounds are due for review monthly, and the midterms page needs an update after November 3.
- 2026-10-31: **The tab bar arrived with step 5, and the Quiz tab shows "coming soon"** until step 6, so the approved navigation is in place now. Routes use the URL hash (`#/topics/<id>`) because GitHub Pages serves a single static page.
- 2026-10-31: **The Today page ships without the tab bar, topic tags, streak, or review card for now.** Those depend on topics (step 5), the quiz (step 6), and review (step 7), and each one gets added in its own step. A short footer names all 8 outlets and explains the cross-check, which also covers the feed terms' credit requirement.
- 2026-10-31: **Highlights compare headlines instead of showing a summary.** Each card leads with the most central outlet's headline (smallest Ad Fontes bias, then highest reliability). "Show outlets" lists every outlet's own headline. It's free, follows the feed terms, and shows how each side framed a story. The alternatives were AI-written summaries (a paid key, unchecked) and headline only. This updates the approved design (see `docs/design.md`).
- 2026-10-31: **How the job matches headlines.** Words are cut to 5-letter stems, filler words are dropped, and two headlines match when they share 2+ stems making up 40%+ of the shorter one. Only headlines from the last 36 hours count. Links must point to the outlet's own domain. If fewer than 4 outlets respond, no file is written and the previous day stays up. The job runs once a day at 11:00 UTC (6 am Central in summer, 5 am in winter) and uses `fast-xml-parser` (job only, not shipped to the site). Known weakness: broad stories, like the midterms, can pull loosely related headlines into one group.
- 2026-10-31: **The site stays public but non-commercial.** Most feeds are offered for personal, non-commercial use, so the site has no ads or payments. It shows only headlines, links, and outlet names, never article text or logos, and any summaries would be written in our own words. Sharing the link with friends is fine, but it isn't promoted widely. The alternative was keeping the site for personal use only.
- 2026-10-31: **8 outlets, using RSS feeds instead of APIs.** Leaning comes from AllSides, and credibility from an Ad Fontes reliability score of 32 or higher. Amy added The Economist to the proposed 7, which makes the list 3 left, 3 center, 2 right. No other right-leaning outlet with a free feed passed the credibility bar: the New York Post and Washington Times are rated "Mixed Reliability", and the WSJ feed is dead. RSS needs no API keys, so the daily job has no secrets. Paywalled links (NYT, The Economist) are marked on the page.
- 2026-10-31: **Tool versions are Vite 8, Vitest 5, and TypeScript 7, with Node 24 in CI.** These are the current releases, and all three are dev tools only, so nothing ships to the browser except our own code. The deploy runs `npm test` and the type check before publishing, so a failing test blocks the deploy.
- 2026-10-30: **The look is calm news + playful quiz.** The Today and Topics screens look like a clean newspaper (Source Serif 4 and Inter, white background, navy accent). The quiz and review screens are game-like (Nunito, cream background, orange accent, rounded cards). This keeps serious topics like wars feeling trustworthy while keeping the recall part fun. The alternative considered was a friendly game style everywhere.
- 2026-10-27: **Headlines are cross-checked.** A story appears only when 2 or more credible outlets with different leanings (left, center, or right, using AllSides and Ad Fontes Media ratings) report it, and every outlet is shown and linked. This cuts down on one newsroom's slant and on thinly sourced stories. If no story passes, the page shows fewer highlights rather than a single-source one. Grouping starts with word matching, and an AI step could be added later if matching proves too weak. Replaces the single news API in the decision below.
- 2026-10-27: **Topics: the agent proposes 4–6 major ongoing stories with reasons, and Amy approves or swaps them.** The list is reviewed monthly. Alternatives considered: Amy picks every topic, or topics are chosen automatically by how often they appear in headlines.
- 2026-10-27: **The timeline game becomes the weekly quiz's main round** instead of a separate daily history game. That means one game to build, tied to the news. Replaces the "daily timeline game" decision below.
- 2026-10-27: **News content is mixed.** Daily headlines come automatically from a news API through a scheduled GitHub Action, with the key kept as a GitHub secret and never shipped to the browser. The weekly quiz and topic updates are written by the agent and skimmed by Amy, so quiz facts are checked. Alternatives considered: a weekly batch written entirely by hand (news up to a week old), and daily AI-written summaries (costs money each day and goes live unchecked, which is risky for contested topics). Replaces the "content is written ahead" decision below for news. History and background are still written ahead.
- 2026-10-27: **Agent instructions live in `AGENTS.md`**, so Codex and Claude Code read the same file. `CLAUDE.md` is just `@AGENTS.md`.
- 2026-10-27: ~~Daily format is a timeline game with mixed topics.~~ (Replaced, see above.) Amy finds articles dull and wants something that feels like a game or a conversation. Alternatives considered: a 5-question quiz, a lesson card plus quiz, a "What am I?" mystery with clues, and a map guess.
- 2026-10-27: ~~Content is written ahead in repo data files.~~ (Replaced for news, see above.)
- 2026-10-27: **Platform is TypeScript + Vite on GitHub Pages**, deployed by GitHub Actions. Vite `base` must match the repo name (`/daily-knowledge/`).
- 2026-10-27: **No accounts or backend.** The streak, quiz results, and review schedule live in `localStorage`, so progress is per device and browser.
- 2026-10-27: **"Today" uses the player's local date.** US news is the default country for now.
